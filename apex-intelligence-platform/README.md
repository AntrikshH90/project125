# Apex Intelligence Manager

An immersive, gamified team collaboration platform with 3D elements and animations.

## Setup

```bash
npm install
npx prisma migrate dev
npm run dev
```

## Features

- **3D Task Board**: Spatial, draggable task cards
- **Points System**: Gamified task completion
- **3D Visualizations**: Three.js powered dashboard
- **Animations**: GSAP and Framer Motion
- **Responsive Design**: Works on all devices

## Tech Stack

- Next.js 14
- React 18
- Three.js + @react-three/fiber
- GSAP & Framer Motion
- Tailwind CSS
- Prisma

## Running the App

```bash
npm run dev
